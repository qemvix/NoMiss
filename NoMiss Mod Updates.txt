1.2 — Major customization update
All features previously planned for 1.1.2 and 1.2 are combined into 1.2.

- Weapon categories: All swords, spears, axes, maces, pickaxes, shovels and hoes. Each category uses one of 20 weapon slots instead of a slot per tier. Individual-item selections remain available.
- Expanded category support: recognize compatible modded weapons through Minecraft and common item tags, plus piercing-weapon components for spears.
- Per-weapon rules: each category, item type or exact-item slot can inherit its profile’s cooldown/block-breaking defaults or override them.
- Saved profiles and presets: Survival, PvP and Modpack setups; create, duplicate, rename, delete and switch profiles. Profile switching has a rebindable shortcut.
- Cooldown protection starts OFF in EVERY built-in preset and new profile, including PvP. Only enable it by manual choice. Existing manually chosen settings are preserved when duplicating, migrating or importing.
- Automatic server profiles: optionally remember and load the chosen profile per server; restore the manual profile on leaving. Off by default; server assignments stay local and are excluded from exports.
- Redesigned settings: separate General, Weapons, Profiles and HUD pages.
- HUD customization: choose the corner, size and opacity.
- Protected-item indicator: optionally show whether the held item is currently protected.
- Import/export: share profiles and display settings through validated JSON copied to/from the clipboard, with confirmation and an automatic backup before importing.
- Exact-item protection: match a held item’s name, enchantments and other properties; ignore stack count, durability and repair cost. Identical copies match. Renaming or changing properties requires recapturing the item.

All shortcuts must be rebindable. Each visual indicator must have its own toggle.
This file records the agreed scope; it does not authorize future implementation without a user request.
